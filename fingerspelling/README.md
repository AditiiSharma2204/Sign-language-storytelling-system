# Fingerspelling alphabet assets

Drop one file per letter in this folder and SignStory will use it automatically (no restart needed):

    a.png  b.png  c.png ... z.png        (.jpg, .jpeg, .webp and short .mp4 clips also work)

- **Images** are centred on a 640x480 canvas and held for 0.7 s per letter.
- **Clips** (.mp4) are used as-is, so they can show the motion for J and Z.
- Any letter without a file falls back to a large letter card, so partial sets are fine.
- The Dictionary tab shows which letters are covered.

Use images you have the right to redistribute (your own photos, or public-domain / CC0 alphabet charts).
