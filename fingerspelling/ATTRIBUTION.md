# Fingerspelling image attribution

The letter images in this folder are the American Sign Language manual alphabet, downloaded from
Wikimedia Commons (rendered to 960 px PNG from the original SVGs). Commons lists every file as **Public domain**;
the original artwork is from [wpclipart.com](http://www.wpclipart.com/sign_language/American_ABCs/index.html).
Attribution is not required for public-domain works but is given here for transparency.
